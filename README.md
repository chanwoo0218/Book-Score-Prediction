# 도서 평점 예측

> 사용자 특성과 도서 메타데이터를 결합해 사용자가 특정 도서에 부여할 **1~10점 평점**을 예측한 추천시스템 기반 회귀 프로젝트입니다.

## 프로젝트 개요

| 항목 | 내용 |
|---|---|
| 수행 기간 | 2026.01.06 ~ 2026.02.25 |
| 문제 유형 | 추천시스템 기반 평점 회귀 |
| 데이터 | 전처리 후 131,865건, 사용자 11,452명, 도서 16,930권 |
| 최종 모델 | 범주형·텍스트·수치형 변수를 결합한 CatBoost |
| 평가 지표 | RMSE, MAE, R² |
| 평가 방식 | 사용자 기반 warm-start holdout |

## 문제 정의

평점 예측 데이터는 한 행이 사용자와 도서의 상호작용을 뜻하며, 사용자·도서 ID의 고유값이 많고 상호작용이 희소합니다. 이 프로젝트는 단순 사용자 평균보다 사용자 정보와 도서 메타데이터를 함께 사용한 모델이 평점 예측을 개선할 수 있는지 검증했습니다.

## 데이터 처리

- 평점 `0`은 실제 0점 선호가 아니라 암묵적 피드백으로 해석하여 제외
- 제목·저자·출판사·지역 문자열 정규화
- 지역에서 국가 정보 추출
- 결측치와 비정상 출판연도 처리
- 사용자와 도서가 각각 최소 3개 상호작용을 갖도록 반복적인 3×3 p-core 필터링
- 동일 사용자의 일부 기록을 평가에 남기는 warm-start 분할

전처리 완료 데이터는 `data/processed/df_final1.csv`에 포함되어 있습니다. 원본 대회 데이터는 100MB를 초과하거나 재배포 조건 확인이 필요해 저장소에 포함하지 않았습니다.

## 모델링

1. 사용자 평균 기준모델
2. 텍스트 TF-IDF → Truncated SVD와 수치형 변수로 Linear Regression/Ridge 비교
3. 사용자·도서·연대 범주형 변수와 텍스트 파생 변수를 결합한 CatBoost
4. 검증 세트 조기 종료 후 선택 반복 수로 train+validation 재학습

## 주요 결과

| 모델 | 테스트 RMSE | 테스트 MAE | 테스트 R² |
|---|---:|---:|---:|
| UserMean 기준모델 | 1.6412 | 1.2406 | - |
| Ridge 최종 | 1.55868 | 1.20898 | 0.24077 |
| **CatBoost 최종** | **1.55290** | **1.19926** | **0.24639** |

CatBoost는 사용자 평균 기준모델 대비 RMSE를 약 `0.0883`, MAE를 약 `0.0413` 낮췄습니다.

## 한계와 개선 방향

- 완전히 새로운 사용자·도서를 대상으로 한 cold-start 성능은 별도 검증이 필요합니다.
- 평점 오차를 예측했으며 NDCG, Recall@K 같은 추천 순위 지표를 직접 최적화하지 않았습니다.
- 행렬분해, 협업 필터링, 신경망 기반 추천모델과의 추가 비교가 필요합니다.
